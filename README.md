## 🚀 How to Run the Programs

1. Clone this repository:

   ```bash
   git clone https://github.com/diksha1906732/Java-Programming-Practice.git
   ```

2. Open the project folder in VS Code.

3. Compile a Java program:

   ```bash
   javac FileName.java
   ```

4. Run the program:

   ```bash
   java FileName
   ```

   Replace `FileName` with the actual class name containing the main method.
